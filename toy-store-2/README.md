# Toy Store 2 — PlaySpace Kids

A separate, homely PlaySpace Kids storefront prototype committed in `toy-store-2/` inside this repository. The existing root WOODKIND project is not replaced.

## Preview
- Storefront: open `index.html`
- Admin demo: open `admin.html`
- Admin demo code: `playspace-demo`

## Features
- 28 products and bundles from the supplied business plan catalogue
- Five product categories, search, filters, detail modal, enquiry basket
- Original category illustration artwork
- Admin demo to add/edit/delete products, edit price and stock, upload an image, export/import JSON, and view the local enquiry selections

## Important limitations
This is a front-end preview. Admin changes and enquiry selections save in browser localStorage only; they do not sync between devices or to GitHub. The demo access code is not real security. Category artwork is illustrative, not verified photos of every SKU. Prices remain unconfirmed, and product-specific dimensions, materials, age ratings, load limits, installation and safety requirements must be verified with suppliers. Connect secure authentication, a database, image storage and a real order/enquiry backend before a public commercial launch.
